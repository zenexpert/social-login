Overview

The Social Login plugin provides a seamless, multi-provider OAuth 2.0 authentication system for Zen Cart. Built on the industry-standard PHP League OAuth client, this encapsulated extension allows customers to register and log in using their existing Google, Facebook, or Apple identities without leaving your storefront.

Core Architecture & Features

  • Unified Callback Routing: Employs a single dynamic endpoint for all OAuth providers, drastically simplifying integration and allowing for rapid expansion to future providers.
  • WAF & ModSecurity Bypass: Utilizes form_post response modes combined with local session recovery bounces to prevent firewall 406 errors (Remote File Inclusion false-positives) without requiring server-level rule whitelisting.
  • Cart & Session Preservation: Actively intercepts cross-origin cookie drops triggered by modern SameSite=Lax browser policies. Carts built prior to logging in are safely retained and merged into the authenticated session.
  • Automated Account Provisioning: Safely parses missing provider data (e.g., Apple's proxy emails or Facebook's phone-only accounts) and seamlessly links external social identities to existing Zen Cart customer database records.

Installation

This plugin is built as a strict Encapsulated Plugin for Zen Cart 2.x. It utilizes reference-based observers and a self-contained directory structure, guaranteeing absolutely zero core file modifications.

  1. Backup your database.
  2. Upload the SocialLogin folder to your store's zc_plugins directory.
  3. Navigate to your Zen Cart Admin and go to Plugins > Plugin Manager.
  4. Locate Social Login and click Install. The necessary database tables and configuration keys will automatically generate.
  5. Configure your desired social providers in the Admin configuration menu using the tabs above for provider-specific instructions.

Google Configuration

  1. Log in to the Google Cloud Console.
  2. Click Select project in the top left corner. If you already have a project, click on that button. A popup window will show; click New project.
  3. Give your project a name (e.g., Zen Cart Login) and create it. Once it's created, ensure it is selected as the active project.
  4. Navigate to API & Services.
  5. Click OAuth consent screen in the side menu and select Get Started.
  6. Give your app a name (you can use Zen Cart Login again), set audience to External, set your contact info, agree to the policy, click Continue, and finally Create.
  7. Go to Branding in the side menu. In App Domain, add links as requested. Add an authorized domain (the domain where you'll be using this app) and save changes.
  8. Go to Data access in the side menu and click Add or remove scopes. Add the three non-sensitive default scopes required for identity verification:
    • .../auth/userinfo.email (Access the user's email address)
    • .../auth/userinfo.profile (Access basic profile information like name)
    • openid (OpenID Connect scope for identity verification)
    Click Update, then Save.
  9. Go to Audience in the side menu and click Publish App.
  10. Go to Clients in the side menu and click Create client.
  11. Set Application type to Web application and give it a name (e.g., Zen Cart Login).
  12. Under Authorised redirect URIs, click Add URI and set it to:
    https://YOUR_DOMAIN.com/PATH_TO_YOUR_SHOP/index.php?main_page=social_oauth_callback&provider=google
    Click Create.
  13. Copy your Client ID and Client Secret into your Zen Cart admin Social Login configuration page.
  14. Your site is now ready to use Google Login.

Facebook Configuration

Note: Before you proceed, please keep in mind Facebook Login is only available for Verified Businesses. If you have a business, you'll be required to verify it before you can use the feature.
  1. Go to Meta for Developers. If you don't have an account, you'll have to create one.
  2. Navigate to My Apps and click Create App.
  3. Name your app (keep in mind it's visible to users, so you might want to name it YOUR_SITE Social Login).
  4. Select Authenticate and request data from users with Facebook Login, select the business portfolio to use with this app, and complete the steps in the wizard.
  5. In your Dashboard, go through each step that doesn't have a green checkmark.
  6. Under Customize the Authenticate and request data from users with Facebook Login use case, you will need to add email under permissions. You only want email and public_profile, nothing else.
  7. Go to Settings and set Valid OAuth Redirect URIs to:
    https://YOUR_DOMAIN.com/PATH_TO_YOUR_SHOP/index.php?main_page=social_oauth_callback&provider=facebook
    Click Save.
  8. Go to App Settings > Basic and fill out all details. A link to your site's Privacy Policy, Terms of Service, and Data Deletion pages is required. You will also need to upload a 1024x1024px (or larger) image that will be used as the App icon. Ensure you prepare an image with a transparent background.
  9. Scroll down, click the Add platform button, and select Website.
  10. Provide the URL to your website and click Add or update instructions. Fill out all required information (for "Is Facebook Login integrated on this platform?", select No).
  11. Save your changes and publish the app.
  12. If there are still any errors or warnings, fix them before publishing. Apps go through verification, so wait until your app is approved before enabling it on your website.
  13. Once approved, go to App settings > Basic, click the Show button to reveal your App secret, and copy your App ID and App Secret into your Zen Cart admin Social Login configuration page, then enable Facebook login.
  14. Your site is now ready to use Facebook Login.

Apple Configuration

Configuring Apple requires cryptographic keys and strict domain verification. You must have an active, paid Apple Developer account to generate these credentials.

Step 1: Create an App ID

  1. Log into the Apple Developer Portal and navigate to Certificates, Identifiers & Profiles.
  2. Go to Identifiers, click the + icon, and select App IDs.
  3. Register a primary App ID (e.g., com.yourstore.app).

Step 2: Create and Configure a Service ID

  1. Return to Identifiers, click the + icon, and select Services IDs.
  2. Define an identifier (e.g., com.yourstore.app.login). This specific string serves as your Apple Service ID (Client ID) for the Zen Cart admin panel.
  3. Click into the newly created Service ID, check the box for Sign In with Apple, and click Configure.
  4. Assign your primary App ID from Step 1 as the Primary App ID.
  5. Under Web Domain, enter your store's root domain (e.g., yourstore.com).
  6. Under Return URLs, paste your exact OAuth callback URL (e.g., https://yourstore.com/index.php?main_page=social_oauth_callback&provider=apple).
  7. Save the configuration.

Step 3: Generate the Auth Key

  1. Navigate to the Keys menu in the left sidebar and click the + icon.
  2. Name the key (e.g., "Store Social Login") and check the box for Sign In with Apple.
  3. Click Configure and link it to your primary App ID.
  4. Click Register and then Download to save the .p8 file to your computer. Note: Apple strictly limits this download to a single occurrence.
  5. Copy the 10-character Key ID displayed on this confirmation page.

Step 4: Retrieve Your Team ID

  1. Locate your 10-character Team ID, which is permanently displayed in the top-right corner of the Apple Developer portal beneath your developer account name.

Step 5: Securely Host the .p8 File

  1. Upload the downloaded .p8 file to your web server via FTP/SFTP.
  2. Security Requirement: Place this file outside of your public_html (or web root) directory so it cannot be directly requested or downloaded via a web browser.
  3. Note the absolute server path to this file (e.g., /home/username/apple_keys/AuthKey_XXXXXXXXXX.p8).

Step 6: Zen Cart Admin Configuration

  1. Log into your Zen Cart admin panel and navigate to the Social Login configuration menu.
  2. Set Enable Apple Login to true.
  3. Enter the Apple Service ID (from Step 2).
  4. Enter the Apple Team ID (from Step 4).
  5. Enter the Apple Key ID (from Step 3).
  6. Enter the Apple Key File Path (the absolute server path from Step 5).
